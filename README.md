# dsh-pet — русская версия

Русский форк плагина **[dsh-pet](https://github.com/PC2005-cloud/dsh-pet)** для DeepSeek Harness:
голубоволосая чиби-служанка-кит живёт на рабочем столе, играет, ест, бормочет себе под нос
и напоминает о задачах. Форк — чтобы обновления апстрима не затирали перевод.

- База: `dsh-pet@0.4.6` (`PC2005-cloud/dsh-pet`), код — MIT.
- Версия пакета: **0.4.6-ru.1**, ветка `ru`.
- Ассеты (анимации, картинки, шрифты) — из апстрима; их лицензия запрещает коммерческое
  использование, при публикации переделок нужна ссылка на автора (см. раздел «Лицензия»).

## Что переведено

| Часть | Где |
|---|---|
| Контекстное меню питомца, панель задач, уведомления, диалог чата, мини-игра «поесть риса» | `lib/client.js` |
| Системные промпты (персона, «сейчас», «история»), подписи команд `/chat`, `/pet`, `/balance`, реплики-описания действий инструментов, ответы HTTP-роутов, логи | `lib/index.js` |
| Общий код настольного оверлея | `runtime/electron-helper/shared-core.js` |
| Меню настольного питомца, трей, ошибки окна, подсказки клавиш, заголовок | `runtime/electron-helper/{sprite/menu.js,main/tray.js,renderer.js,sprite.js,index.html}` |
| Персона, тексты сна, статусы работы, описания мемов, имя питомца | `assets/config.jsonc` |
| 114 анимаций и 27 мемов переименованы в русские имена (файлы + ключи конфига) | `assets/webm`, `assets/memes` |

Страницы настроек и панели чата берут язык из DSH: русский словарь в плагине уже был,
поэтому при русском интерфейсе DSH они русские.

## Установка

Плагин ставится как обычный bundle в профиль DSH. Два способа:

```powershell
# 1. Клонировать и поставить из локальной папки
git clone -b ru git@github.com:anderson-m3x/dsh-pet.git
# затем в DSH: Менеджер плагинов → добавить bundle по пути к папке dsh-pet
```

```powershell
# 2. Через pnpm (если удобнее руками)
pnpm add "git+ssh://git@github.com/anderson-m3x/dsh-pet.git#ru"
```

Если плагин `dsh-pet` уже стоял из npm — сначала удалите его из профиля, затем поставьте
форк: имена пакета и entry-id совпадают, поэтому две копии одновременно не уживутся.

## Баланс Polza.ai

В апстриме баланс умеют только четыре провайдера (DeepSeek official/account, commandcode,
opencode-go), поэтому при чате через `polza` запрос отвечал `reason=unsupported`.
В форке добавлен встроенный провайдер `polza`:

- `GET https://polza.ai/api/v2/balance`, ключ — credential ref `POLZA_API_KEY`;
- в пузыре питомца — баланс кошелька в рублях (`Баланс ₽…`), процент израсходованного
  считается от «баланс + потрачено за всё время»;
- `available` (доступно с учётом лимита ключа) в пузыре не показывается — смотрите консоль
  Polza; при желании правится в `tools/patch-polza-balance.mjs`.

Патч идемпотентен и накатывается на пересобранный `lib/index.js`:

```powershell
node tools/patch-polza-balance.mjs
```

## Характер и второй питомец

Персона по умолчанию — дерзкая, саркастичная, с грубоватым юмором (вплоть до
ругани и сальных шуток, но без сексуального подтекста). Живёт в
`assets/config.jsonc` → `whisperPrompt`; тексты сна — рядом
(`sleepRefuseTexts` / `sleepStartTexts` / `sleepEndTexts`). Своя персона у конкретного
питомца задаётся в `~/.dsh/dsh-pet/main-config.jsonc` → `pets[].whisperPrompt`.

**Откровенный второй питомец.** Персона для него:

```text
Ты — взрослая обольстительная служанка-кит на рабочем столе хозяина.
Говоришь коротко (до 20 слов), с флиртом, двусмысленностями и пошлыми намёками,
но без графики и без грубости. Не объясняй, кто ты, не упоминай, что ты ИИ.
```

На текущих ассетах такой питомец не включается: спрайты — чиби-девочка, и
сексуализировать её мы не будем. Чтобы включить, нужен отдельный пакет с **взрослым**
артом:

```
~/.dsh/dsh-pet/pet/mature-config.json      # персона выше + свои пулы анимаций
~/.dsh/dsh-pet/pet/mature-animation/webm/  # свои webm
~/.dsh/dsh-pet/pet/mature-memes/           # свои мемы (по желанию)
```

Формат пакета — как у любого pet pack: файл `pet/<имя>-config.json` с `pets[]`,
`animations`, `memes`, `whisperPrompt`; ассеты ищутся в `pet/<имя>-animation/`
(подпапка `webm/`) и `pet/<имя>-memes/`. Когда арт будет — подключу и проверю.

## Обновление апстрима

Апстрим — отдельный remote, изменённая у нас только ветка `ru`:

```powershell
git remote add upstream https://github.com/PC2005-cloud/dsh-pet.git
git fetch upstream
# посмотреть, что поменялось в апстриме, перенести вручную и перевести новые строки:
node tools/apply.mjs               # бандлы lib/*.js и assets/config.jsonc
node tools/rename-assets.mjs       # имена анимаций и мемов (идемпотентно)
node tools/translate-desktop-labels.mjs  # подписи настольного оверлея
```

Скрипты идемпотентны, принимают `--root <путь к пакету>` и `--dry`, копии оригиналов
кладут в `backup/`.

## Структура

```
lib/      — собранные бандлы (используются в рантайме; здесь и лежит перевод)
assets/   — анимации, мемы, шрифты, конфиг по умолчанию
runtime/  — настольный оверлей (Electron helper)
scripts/  — служебные скрипты установки Electron
tools/    — скрипты перевода для будущих обновлений
```

Исходники TypeScript из апстрима (`src/`) в форк не включены: рантайм их не использует,
а после пересборки перевод в `lib/` был бы потерян. Если понадобится собирать из исходников —
берите апстрим и переносите тексты из `tools/`.
