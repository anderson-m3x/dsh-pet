# Русификация dsh-pet 0.4.6

Набор скриптов, которые переводят установленный плагин `dsh-pet` на русский «на месте»:
правятся собранные бандлы в `node_modules/dsh-pet`, исходники (`src/`) не трогаются —
они не участвуют в рантайме.

## Что переведено

| Файл | Что внутри |
|---|---|
| `lib/client.js` | веб-оверлей: контекстное меню питомца, панель задач, уведомления, диалог чата, ошибки, «поесть риса» |
| `lib/index.js` | хост: системные промпты (персона, «сейчас», история), подписи команд `/chat`, `/pet`, `/balance`, реплики-описания действий инструментов, ответы HTTP-роутов, логи |
| `runtime/electron-helper/shared-core.js` | общий код настольного оверлея (меню, пузыри, задачи, баланс) |
| `runtime/electron-helper/sprite/menu.js`, `main/tray.js`, `renderer.js`, `sprite.js`, `index.html` | меню настольного питомца, трей, ошибки окна, подсказки клавиш, заголовок |
| `assets/config.jsonc` | персона, тексты сна/пробуждения, статусы работы, описания мемов, имена питомца |
| `assets/webm/*.webm`, `assets/memes/*.png` + ключи в конфиге | 114 анимаций и 27 мемов переименованы в русские имена |
| `package.json`, `README.md` | описание пакета и readme |

## Что осталось китайским

- комментарии в `assets/config.jsonc` и `cordis.patch.yml` (документация для правки конфига);
- внутренние `console.*`-логи клиента и сообщения провайдеров баланса (в UI не видны);
- исходники в `src/` — не исполняются;
- словари локалей (`zh/en/ja/es/fr/de/ru/pt`) не тронуты: страницы настроек и панель чата
  берут язык из DSH, русский словарь в плагине уже был.

## Порядок применения

```powershell
$node = 'C:\Users\New\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe'
& $node .\apply.mjs
& $node .\rename-assets.mjs
& $node .\translate-desktop-labels.mjs
```

Каждый скрипт идемпотентен: повторный запуск ничего не портит. Копии оригиналов —
в `backup/`. Скрипты принимают `--root <путь к пакету>` и `--dry`.

После применения плагин нужно перезагрузить (выключить/включить `include:dsh-pet`
в менеджере плагинов) и обновить страницу Web-интерфейса — клиентский бандл кешируется.

## Важно

- Пакет в профиле заменён независимой копией: жёсткие ссылки на pnpm-store разорваны,
  сам store не изменён (оригиналы восстановлены перед копированием).
- Любое обновление dsh-pet затрёт перевод — скрипты можно запустить снова.
- `rename-assets.mjs` меняет имена файлов: если у пользователя есть свои pet-pack’и
  с китайскими именами, их нужно переименовать вручную или не запускать этот шаг.
